Google Earth Engine + Sentinel-2 + Random Forest

Land Use / Land Cover Classification

A supervised classification workflow that labels Sentinel-2 imagery into five land cover classes using a Random Forest classifier trained on labeled sample points, built entirely in Google Earth Engine.

LULC Classification

Land cover classes

  • Trees
  • Water
  • Built-up
  • Bareland
  • Grassland

Training samples were digitized for each class and used to train a Random Forest classifier directly on Sentinel-2 bands within Earth Engine, producing a classified land cover raster across the study area.
